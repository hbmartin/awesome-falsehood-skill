# Prepared Source Index

Citation-only index for the prepared falsehood topic digests. These links point to upstream sources; mirrored upstream article bodies are not kept in this repo.

Each entry has a stable citation key such as `T5`. The topic digests cite these keys in their `Sources` sections and next to specific anecdotes, so review output can attribute a falsehood to its upstream article without loading this whole index.
